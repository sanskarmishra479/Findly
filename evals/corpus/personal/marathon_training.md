# 16 week marathon plan

Weeks 1-4: three easy runs of 5-8 km plus one long run that grows from 12 to 16 km.
Weeks 5-10: add a tempo run on Wednesdays; long run up to 28 km.
Weeks 11-14: peak mileage, one 32 km long run in week 13.
Weeks 15-16: taper, cut distance by half, keep a little speed work.
Race day target pace: 5:40 per km.
